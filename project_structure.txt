Key Statistics:
---------------
• Total Samples: 652 images (4 classes)
• Dataset Split: 60% train / 20% val / 20% test (stratified)
• Feature Dimensionality: 26,468 combined features
  - HOG: 26,244 dimensions
  - Color Histogram (HSV): 96 dimensions
  - SIFT Bag-of-Words: 128 dimensions

• Class Order (by complexity):
  resistor → capacitor → transistor → IC

• Best Model Performance (Test Set):
  - Integer Random Forest: 79.39%
  - Integer SVM: 77.86%
  - Ordinal SVM: 77.10%
  - Ordinal Random Forest: 75.57%


Pipeline Workflow:
------------------
1. Data Preparation (01_prepare_data.py)
   → Stratified split into train/val/test sets

2. Feature Extraction (02_extract_*.py)
   → HOG, Color Histogram, SIFT extracted separately

3. Feature Combination (03_combine_features.py)
   → Combine all features, scale, generate both integer & ordinal labels

4. Model Training (04_train_*.py)
   → Train SVM and Random Forest with both encoding approaches

5. Visualization (05_visualize.py)
   → Generate feature visualizations for analysis

6. Evaluation (06_compare_models.py)
   → Compare integer vs ordinal classification performance
